# Network and Its Classification

## 1. What is a Network?
A **network** is a collection of two or more interconnected devices (computers, servers, routers, etc.) that can **share data, resources, and services**.

**Purpose:** Communication, resource sharing, centralized management.  
**Examples:** Internet, school LANs, office networks.

---

## 2. Classification of Networks

Networks can be classified based on **geographical area** and **IP/Device classes**.

### A. Based on Geographical Area

| Type | Description | Example |
|------|-------------|---------|
| **PAN (Personal Area Network)** | Very small area, usually for personal devices | Bluetooth devices, smartwatches |
| **LAN (Local Area Network)** | Covers a small area such as a room, building, or campus | School computer lab network |
| **CAN (Campus Area Network)** | Connects multiple buildings within a campus | University network |
| **MAN (Metropolitan Area Network)** | Covers a city or large campus; connects multiple LANs | City government network |
| **WAN (Wide Area Network)** | Covers a large area, often worldwide | Internet |
| **SAN (Storage Area Network)** | Dedicated network for connecting storage devices | Data center storage network |

---

### B. Based on IP Address Classes

| Class | First Octet Range | Network Size | Usage |
|-------|-----------------|--------------|-------|
| **A** | 1 – 126 | Very large networks (≈16 million hosts) | Large organizations, ISPs |
| **B** | 128 – 191 | Medium networks (≈65,000 hosts) | Universities, large businesses |
| **C** | 192 – 223 | Small networks (≈254 hosts) | Small offices, private networks |
| **D** | 224 – 239 | Multicast | Broadcasting to multiple hosts |
| **E** | 240 – 255 | Experimental | Reserved for research, not public use |

---

### Summary
- **Network:** Connects devices for sharing resources.  
- **Geographical classification:** PAN, LAN, CAN, MAN, WAN, SAN.
